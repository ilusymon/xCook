# 星厨房 · 卡通小厨房

2026-10-12：用户明确选择卡通化，替代此前的摄影与杂志排版方向。`concept.png` 是菜单、愿望单、厨房三个页面的视觉概念，由内置 imagegen 生成，并非小程序运行截图。

## 视觉方向

- 暖奶油底色 `#FFF9EA`，巧克力色线条与文字 `#593B30`。
- 珊瑚橙 `#FF9278` 用于主要操作；奶油黄 `#FFE293`、浅蓝 `#BDDCED` 用于分类与状态辅助。
- 情侣小厨师采用统一的二维绘本画风；人物和食物都有圆润的线条与轻微纸张质感。
- 菜单以手绘菜品为主；愿望详情采用便签餐单；厨房以待办卡片和食材图标组织入口。
- 圆润标题、细描边、少量实色投影、轻量心形装饰。避免整页格纹和每个区域重复相同卡片。

## 生成提示词摘要

为星厨房生成三屏卡通微信小程序 UI 概念：菜单、愿望单、厨房。二维手绘绘本风，暖奶油、巧克力描边、珊瑚橙、奶油黄和浅蓝配色。统一的情侣小厨师角色与番茄牛腩、厚蛋烧、玉米排骨汤插画。中文圆润标题、清晰操作层级、便签式愿望餐单、可触达的操作按钮和一致底部导航。不使用摄影、杂志衬线排版、深色橄榄面板、支付或情侣绑定入口。

## 页面实现

已落地全部 15 个注册页面的卡通视觉。菜单、愿望单和厨房采用参考图的主要结构，其余页面统一配色、标题、轮廓、按钮和表单。参考图中的示例菜名、数量和状态没有作为假数据写入业务。

- 菜单：缩短情侣做饭头图，采用左侧文字分类、右侧紧凑菜品的双栏布局。右侧连续展示分类分组，滚动时左侧同步高亮并滚入可见区域；点击左侧跳到对应分组。搜索覆盖全菜单。插画菜品卡、已选徽标、黄色餐单栏和确认按钮保留，点击餐单栏可展开调整各口味数量。
- 愿望单：传递心愿头图、四种状态筛选、夹子便签、真实菜品与口味、给大厨的话、心形进度和角色对应的操作。
- 厨房：小厨师开工头图、待处理 / 制作中 / 拿手菜统计、实际愿望待办、四个插画管理入口。已接下的愿望可从管理页“待制作”筛选重新进入。
- 首页、记录、个人页沿用同组插画和图标；详情、确认、制作、菜品与分类管理使用同一套纸张色、手写标题和轮廓。

文案与操作使用真实 WXML 组件。storybook-header 负责品牌、安全区和三种场景；dish-art 优先显示真实上传封面，加载失败或未设置时使用对应插画。牛腩、厚蛋烧和排骨汤对应三个插画格，其他菜品显示通用餐盘；kitchen-art 复用四格工具插画。底部导航使用同套棕色线条图标。

布局使用自有按钮样式，app.json 不启用 v2 的固定宽度按钮预设。公共 button-reset.wxss 在页面和包含按钮的隔离组件中导入；整行卡片与提交按钮显式全宽，图标按钮保留固定尺寸，防止继承 184px 宽度与水平自动居中。

## 运行素材与源文件

按钮与便签细化：主按钮采用白色手写字、珊瑚色层、左上弧形高光和不规则棕色轮廓。宽版 / 紧凑版底图由 cartoon-controls.wxss 供真实按钮复用，加号保留 88rpx 点击区域。便签采用 paper-top / middle / bottom 三段矢量纸框，固定上下沿高度，侧边随内容撑高；补齐木夹、叶枝、铅笔、粉色留言和心形进度。口味胶囊显示选项值，辅助标签保留选项组名称。

新增九份 SVG 为代码绘制的界面素材，使用明确色层与纹理点，避免依赖 SVG 渐变和 pattern 的解码差异。surface-qa.png 仅用于核对这些矢量素材的轮廓、色彩与衔接，不是微信页面截图。

全部插画由内置 imagegen 生成，引用用户选定的 concept.png，保持同一对人物、描边和水彩质感。四份实际生成提示词保存在 generation-prompts.json。工具图集提示词摘要：同套暖奶油绘本风，2 × 2 图集，胡萝卜菜单夹板、笑脸平底锅与绿色加号、蔬菜篮、心形愿望便签，四格居中、大小一致，不含文字或 UI。
